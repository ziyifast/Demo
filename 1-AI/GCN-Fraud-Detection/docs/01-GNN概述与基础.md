# 一、什么是图神经网络（GNN）

## 1.1 从图说起

在正式介绍图神经网络之前，需要先理解什么是**图（Graph）**。图是一种用于表示对象之间关系的数据结构，由两个基本要素构成：

- **节点（Node/Vertex）**：代表具体的事物，如用户、设备、IP 地址、订单等
- **边（Edge）**：代表节点之间的关系，如"用户 A 使用了设备 X"、"用户 B 和用户 C 共用同一 IP"

在反作弊和风控场景中，实体（账户、设备、IP 等）都可以用节点表示，而这些实体在业务中的关联可以用边表示。

### 图的分类

| 分类维度 | 类型 | 说明 |
|---------|------|------|
| 边的方向 | 无向图 | 边没有方向，如"共用关系" |
| 边的方向 | 有向图 | 边有方向，如"转账关系"（A→B 和 B→A 不同）|
| 节点/边类型 | 同构图 | 只有一种节点类型和一种边类型 |
| 节点/边类型 | 异构图 | 有多种节点类型和多种边类型（风控场景常见）|
| 边权重 | 无权图 | 边只有存在/不存在两种状态 |
| 边权重 | 加权图 | 边有权重，如"转账金额" |

### 图中的基本概念

- **度（Degree）**：一个节点连接的边的数量。在风控中，一个设备关联的用户数就是设备的度
- **邻接矩阵（Adjacency Matrix）**：用矩阵表示节点之间的连接关系
- **路径（Path）**：从一个节点到另一个节点经过的边序列
- **连通分量（Connected Component）**：图中互相连通的最大子图
- **二度关联**：通过一个中间节点间接关联的两个节点

## 1.2 图神经网络（GNN）是什么

图神经网络（Graph Neural Network，GNN）是专门用于处理图结构数据的深度学习方法。GNN 的核心思想是**消息传递机制**——每个节点通过聚合其邻居节点的信息来更新自己的表示，经过多层的迭代，每个节点最终能够感知到图中更远范围的信息。

可以这样理解 GNN 的工作方式：

```
每个节点只看局部信息（邻居节点）
  → 通过层层汇聚掌握全貌
  → 将图结构转换成低维向量表示
```

更具体地说，GNN 的学习目标是为每个节点学习一个**图感知的隐藏状态**，这个状态既包含了节点自身的特征，也融合了其邻居节点乃至整个图结构的信息。

### 消息传递三步曲

GNN 每一层的消息传递包含三个步骤：

1. **发送（Send）**：每个节点将自身的特征信息经过变换后发送给邻居节点
2. **接收（Receive）**：每个节点将邻居节点发送来的信息聚集起来
3. **变换（Transform）**：对聚集后的信息做非线性变换，增加模型表达能力

### 与 CNN 的对比

| | CNN（卷积神经网络）| GNN（图神经网络）|
|---|---|---|
| 处理数据 | 图像（规则网格）| 图（不规则结构）|
| 卷积核 | 固定大小的矩形窗口 | 基于邻居关系的动态窗口 |
| 参数共享 | 空间位置的参数共享 | 节点间的参数共享 |
| 感受野 | 由卷积核大小和层数决定 | 由层数（hop 数）决定 |

## 1.3 为什么 GNN 适合风控场景

GNN 作为近年来新兴的技术，不仅能考虑节点本身的属性，还能同时考虑到网络结构特征，进而刻画黑灰产的关系、团伙以及产业链信息，在风控场景中取得了广泛的应用和效果增益。

### 传统风控方法的局限

传统的风控方法（如规则引擎、孤立森林等）只能分析**单个个体**的行为是否异常，而无法捕捉个体之间的**关联关系**。

但黑灰产恰恰是**团伙化**的——他们利用大量账号协同操作，通过注册、抢优惠、虚假交易等方式牟利。单个账号的行为可能看似正常，但账号之间的关联关系（如共用设备、支付账户、手机号等）却能暴露其团伙属性。

### GNN 的优势

| 能力 | 传统方法 | GNN |
|------|---------|-----|
| 单点特征分析 | ✓ | ✓ |
| 关系网络分析 | ✗ | ✓ |
| 团伙模式识别 | ✗ | ✓ |
| 图结构特征自动学习 | ✗ | ✓ |
| 半监督（少量标签）学习 | 较弱 | 强 |

GNN 正是挖掘团伙关系的核心技术——它能够自动学习图中的结构模式，发现那些"单看正常，关联异常"的欺诈账号。

## 1.4 GNN 家族概览

GNN 是图神经网络的总称，下面是几种主流的 GNN 变体：

| 模型 | 年份 | 核心特点 | 适用场景 |
|------|------|---------|---------|
| **GCN** | 2017 | 谱域卷积，简单高效 | 节点分类、半监督学习 |
| **GraphSAGE** | 2017 | 归纳式学习，支持 mini-batch | 大规模动态图 |
| **GAT** | 2018 | 注意力机制，学习邻居重要性 | 需要可解释性的场景 |
| **GIN** | 2019 | 理论最强的表达能力 | 图分类任务 |
| **HGT** | 2020 | 异构图 Transformer | 多实体多关系场景 |

在风控场景中，最常用的是 **GCN**（入门首选）、**GraphSAGE**（大规模图上使用）、**GAT**（需要可解释性和异构图场景）。

## 1.5 风控中图的构建

在实际风控场景中，一张典型的异构图包含以下实体和关系：

```
节点类型（实体）             边类型（关系）
─────────────────────       ─────────────────────
用户账号 (user)              登录关系 (user → device)
设备指纹 (device)            支付关系 (user → payment)
IP 地址 (ip)                 预订关系 (user → order)
支付账号 (payment)           通讯关系 (user → phone)
手机号 (phone)               共用关系 (同 IP / 同设备)
邮箱 (email)                 交易关系 (user → user)
订单 (order)                 注册关系 (user → ip)
```

通过构建这样的异构图谱，就可以使用 GNN 模型进行：

- **节点分类**：判断每个账号是否为黑产
- **链接预测**：判断两个账号是否属于同一团伙
- **异常子图检测**：发现异常的密集连接区域
