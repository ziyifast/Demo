【第一章：产品概述】

NeoCloud 智能云平台是一款面向中小企业的全栈式云服务解决方案。
我们提供从计算、存储、网络到 AI 推理的一站式服务，帮助客户快速
完成数字化转型。平台自 2020 年上线以来，已服务超过 5000 家企业客户。

核心产品包括：
  - NeoCompute 弹性计算服务
  - NeoStorage 对象存储服务
  - NeoAI 人工智能推理平台
  - NeoShield 安全防护体系

【第五章：常见问题 FAQ】

Q1: 如何注册 NeoCloud 账号？
A1: 访问 www.neocloud-example.com，点击右上角"免费注册"，
    使用手机号或邮箱完成验证即可。新用户赠送 ¥200 体验金。

Q2: 支持哪些支付方式？
A2: 支持企业银行转账、支付宝、微信支付、对公账户汇款。
    企业客户可申请月度账单结算（需通过资质审核）。

Q3: 如何联系技术支持？
A3: - 7×24 热线：400-888-NEO-CLOUD
    - 在线工单：console.neocloud-example.com/tickets
    - 企业微信：搜索"NeoCloud技术支持"
    - 邮件：support@neocloud-example.com

Q4: 数据迁移是否收费？
A4: 从其他云平台迁入 NeoCloud 的数据迁移服务完全免费，
    我们提供专业的迁移工具和技术团队全程协助。

Q5: 如何申请 API 密钥？
A5: 登录控制台 → 访问管理 → API 密钥 → 创建密钥。
    请注意：密钥创建后仅显示一次，请妥善保存。

Q6: NeoAI 支持哪些模型？
A6: 支持主流开源模型（Llama、Qwen、ChatGLM 等），
    也支持客户上传自定义模型。平台提供模型微调和
    一键部署能力。

【第六章：快速上手指南】

6.1 创建第一台云服务器

  1. 登录 NeoCloud 控制台
  2. 点击左侧导航栏 "计算" → "NeoCompute"
  3. 点击 "创建实例"
  4. 选择地域、规格、镜像（推荐 Ubuntu 22.04 LTS）
  5. 设置安全组规则（默认开放 22 端口用于 SSH）
  6. 确认订单并支付，约 30 秒后实例启动完成

6.2 上传文件到对象存储

  1. 进入 NeoStorage 控制台
  2. 创建存储桶（Bucket），名称全局唯一
  3. 上传文件（支持网页上传、SDK、命令行工具）
  4. 设置访问权限（私有/公共读/公共读写）
  5. 通过 CDN 加速域名访问文件
